# Инструкции для автора и агента

Сохраняйте чужие изменения. Local владеет prepare/up/status/down, Compose,
state и доставкой готовых site/native/checks; курсы и Platform владеют своими
публичными командами. Учебное содержание Java и System Practice фиксировано.
Один файл или договор имеет одного владельца; рецензент принимает чужую дельту.
Sol/high — координация, критичные договоры и рецензия; Sol/medium — ограниченная
механика; Sol/max — ключевая архитектура. Terra — ограниченная служебная
работа с проверкой Sol/high. Standard сохраняется, глобальные настройки не меняются.

Инструменты берите из PATH; Arch-пакет и исполняемый файл Task — `go-task`
(`/usr/bin/go-task`); наличие `task` не предполагается. Системный tsc
и Compiler API проверяются отдельно, включая реальное AST-преобразование
и установленный CLI. Параллельные прогоны изолируют temp, output, Compose project,
порты и state; запись в общий output/DB согласуется с владельцем.

prepare сохраняет прежнюю выдачу при ошибке. up использует готовые байты,
стабильный courseDir и постоянные DB/ключи/state, ждёт успеха native server job.
Повторное обновление сохраняет numeric course/instance IDs и ответы.
Dev loader и production sync сохраняют разные auth-договоры.
Preview, Moodle/LTI и Workspace имеют отдельную фактическую приёмку.
VM и старые оценки требуют отдельного прямого разрешения; текущий перенос
ограничен пользователями и правами, прежняя установка и данные сохраняются.
Секреты и пользовательский state остаются вне Git.

Проверяйте реальные публичные договоры и существенные отрицательные сценарии
с независимым рецензентом. Квитанции допуска, полные стенограммы,
самопроверка сообщений и обязательный TDD не нужны. Исторические планы,
START и docs/superpowers используются как справка без прежних обязательств.
Собственных навыков нет, дополнительные `SKILL.md` не создаются; чужие
навыки в зависимостях не редактируются.
Документацию и описания PR пишите по-русски по
[общему правилу](https://github.com/Afonenko-Course-Tools/quarto-course/blob/main/docs/russian-language-policy.md),
сохраняя технические идентификаторы буквально.
