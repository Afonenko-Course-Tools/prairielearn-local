# План переносимого локального стенда

> Исполнители: использовать согласованное параллельное выполнение в S2/S3/S5; у каждого файла один владелец. Пользователь уже поручил реализацию, новое общее подтверждение не требуется.

**Цель:** создать воспроизводимый Compose-комплект и PR в Afonenko-Course-Tools/prairielearn-local.

**Архитектура:** опубликованные Platform/Gateway, воспроизводимая тестовая Moodle, готовый native-курс и постоянные хранилища. Небольшие одноразовые сервисы выполняют первоначальную установку; повторный up сохраняет состояние.

**Стек:** Docker Compose, штатные CLI/API PrairieLearn и Moodle, JSON-конфигурации приложений, shell/Python/PHP только для инициализации.

**Спецификация:** ../specs/2026-11-06-local-stack-design.md

## Общие ограничения и проверка

Все исходники и инструкции русские; технические имена неизменны. Только Sol, усилие medium для подготовки. Не использовать пути /home/tolya, имена старых контейнеров, локальные непубликуемые образы, реальные ключи/аккаунты или course IDs. Не выполнять Docker вне S1. Контейнеры запускаются только в отдельном проекте после root review и проверки памяти.

Проверить: чистые volumes; повторный up с прежними ключами и пользователями; занятый порт/неверный COURSE_DIR с понятной ошибкой; обычную проверку TLS без обходов; согласованность HOST_JOBS_DIR и Workspace home. Обновление курса не сбрасывает историю.
